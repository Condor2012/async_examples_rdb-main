# Описание

Этот репозиторий содержит примеры кода к занятию по теме "Асинхронность"

# Как пользоваться

1. Для того чтобы запускались примеры нужно сгенерить тестовые файлы file1.txt, file2.txt, file3.txt (убраны из репозитория чтобы не тянуть много кода). Они создаются кодом из src/main.rs путём компиляции и сборки
```bash
cargo run
```

2. Все примеры запускаются при помощи команды (например для примера tree_files_sync.rs)
```bash
cargo run --example tree_files_sync
```

3. Для того чтобы посмотреть во что разворачиваются макросы можно использовать:
```bash
cargo expand --example lazy.rs
```
